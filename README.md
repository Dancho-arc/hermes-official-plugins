## 🚀 Getting Started After Installation

The first time you open Hermes Agent with plugins enabled, you will be asked to connect each service you installed. This is a one-time step and usually means signing in to the service you already use, such as your Spotify account or your Home Assistant address.

Once connected, try something simple out loud or in the chat box:

- "Turn off the kitchen lights."
- "Play my evening playlist."
- "What is the temperature in the bedroom?"
- "Pause the music."

Short, clear requests work best. If a request does not land the first time, rephrase it the way you would say it to a person. The assistant learns from the wording you use.

## 🧭 Everyday Tips

Most hiccups have simple causes. If a plugin will not connect, confirm you are signed in to that service in your browser first. If Windows blocks the file, allow it through the security prompt as described in Step 5. Restarting your computer resolves a surprising number of one-time glitches.
